3. HSM_Core API

API说明
HSM_Create(memory)在预分配内存上创建 HSM 实例
HSM_Node_Create(memory)在预分配内存上创建状态节点
HSM_RegisterChildNodes(hsm, parent, params[], n)批量注册子节点到父节点（树构建核心）
HSM_Start(hsm, initial_state)启动状态机，进入初始状态
HSM_SendEvent(hsm, event)从外部注入事件（从当前活跃节点向上冒泡）
HSM_RequestTransition(hsm, target, event)请求状态转换（在回调中调用，延迟到 Process 执行）
HSM_Process(hsm)每帧调用：执行转换队列 + 当前节点 continuous_action
HSM_SetEnable(hsm, bool)启停状态机
HSM_Destroy(hsm)销毁状态机实例

关键机制：事件冒泡 — handler 返回 false 时事件自动传递给 parent 节点。 这允许父节点（如 Mission）捕获子节点未处理的全局事件（如 EV_RESET）。

6. 事件系统

事件 ID名称来源触发路径
0x01EV_CAM_START摄像头Idle→WaitKey2 / Outbound→WaitKey2 / WaitTurnCmd→GoToCross
0x02EV_TURN_LEFT摄像头/蓝牙WaitTurnCmd→TurnLeft
0x03EV_TURN_RIGHT摄像头/蓝牙WaitTurnCmd→TurnRight
0x04EV_DELIVERY_CONFIRM摄像头/蓝牙WaitConfirm→TurnAround
0x10EV_TURN_DONE内部 (continuous)TurnLeft/Right/ExecTurn 完成→下一状态
0x11EV_BT_GO蓝牙Idle→GoToCross / WaitTurnCmd→GoToCross
0x12EV_KEY2_TRIGGER按键WaitKey2→GoToCross
0xFFEV_RESET按键 (Key3)被 Mission 捕获 → Idle（全局复位）

事件冒泡规则：handler 返回 true = 事件已消费，停止冒泡；返回 false = 传递给 parent。 例如：EV_RESET 在叶子节点返回 false → Outbound 返回 false → Mission 捕获后转 Idle。
H+En+Ex+Co = Handler + Entry + Exit + Continuous

7. ActionStack 动作栈（返程回放）

操作触发节点说明
PUSH STRAIGHTIdle (EV_CAM_START/BT_GO)任务开始时压入第一段直行
PUSH STRAIGHTWaitTurnCmd (EV_CAM_START/BT_GO)重新出发时压入直行
PUSH LEFTWaitTurnCmd (EV_TURN_LEFT)左转时压入，返程变为右转
PUSH RIGHTWaitTurnCmd (EV_TURN_RIGHT)右转时压入，返程变为左转
PUSH STRAIGHTGoToCross (终点 0xFF)到达终点前最后一段直行
POP → 空PopAction栈空 = 任务完成 → Idle
POP → STRAIGHTPopAction直行动作 → ExecStraight
POP → LEFT/RIGHTPopAction转弯动作取反 → ExecTurn（左变右、右变左）
去程
S → L → S → R → S → E

→
返程（栈回放）
POP S → POP R(反=左) → POP S → POP L(反=右) → POP S → 空 → Idle

8. HSM vs 传统 FSM 对比

维度HSM (app_fsm + HSM_Core)传统 FSM (f_sm + Finite_State_Machine)
结构树形：Root→Mission→Outbound/Return→叶子节点扁平链表：IDLE→STRAIGHT→TRACKING→STOP→...
嵌套深度4 层（容器节点不占状态位）1 层（所有状态平级）
事件处理冒泡机制：叶子→父→祖父，handler 返回 false 则上浮直接 switch-case，无传播
转移方式HSM_RequestTransition(target) 延迟执行 + 转换队列Transition_To(state_id) 立即执行
全局复位Mission 父节点捕获 EV_RESET，一次性覆盖所有子状态每个状态单独判断 / 外部命令 switch
持续动作每帧 HSM_Process → 当前状态 continuous_action()FSM_App_Run() 大 switch 直接评估转移条件
进出回调entry_action / exit_action 自动调用（含事件参数）手写 Enter_Xxx() 函数
返程逻辑ActionStack (LIFO) 自动回放，转弯方向取反独立硬编码的 RETURN_STRAIGHT / RETURN_TRACKING 状态
实际使用✓ main.c 中启用✗ FSM_App_Init() 已注释
